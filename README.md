# ShakaCode Trust-Based Commercial Licensing

ShakaCode products are built for professional teams, but we want developers to
learn, evaluate, demo, and adopt them without friction.

Our general rule:

> Free to learn, evaluate, demo, and use for qualifying open-source projects.
> Paid when the software creates private business value.

This repository explains ShakaCode's shared licensing philosophy and provides
reusable templates for ShakaCode products.

Product-specific license files control. This repository does not replace the
binding license terms in any product repository.

## Product summaries

- React on Rails Pro — commercial production-use license
- ShakaPerf — source-available / commercial license for private professional use

## Templates

- file headers
- README license summaries
- AGENTS.md licensing instructions
- report attribution language
- package metadata examples

## Important note

Nothing in this repository is legal advice. ShakaCode approved The ShakaStack
License 1.0 and the coverage notice on 2026-11-11 without a counsel review.

## Shared license source

The complete license file delivered with a product release governs that release.
The approved ShakaStack License texts are written in [`license/`](license/README.md)
for future product releases. Version 1.0 was approved on 2026-11-11. The coverage
notice for earlier releases is effective from that date.
This public repository contains no private sales notes or confidential strategy.
